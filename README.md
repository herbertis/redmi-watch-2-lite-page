# ⌚ Redmi Watch 2 Lite - Product Landing Page

[Preview do Projeto](https://herbertis.github.io/redmi-watch-2-lite-page/)

## 💻 Sobre o Projeto

Este projeto consiste no desenvolvimento de uma **Landing Page de produto para o Redmi Watch 2 Lite**, inspirada nos padrões visuais utilizados em páginas oficiais de lançamento de produtos da Xiaomi e vitrines de e-commerce.

A página foi desenvolvida com foco em apresentar os principais recursos do smartwatch de forma clara, visual e envolvente, utilizando **hierarquia visual, seções imersivas e storytelling do produto** para destacar seus diferenciais.

O objetivo foi criar uma interface moderna, altamente responsiva e alinhada com o padrão visual de páginas de tecnologia, proporcionando uma **experiência de navegação intuitiva e focada na valorização do produto**.

A landing page foi construída com foco em **performance, design responsivo e experiência do usuário**, simulando o padrão utilizado em páginas de produto de grandes marcas de tecnologia.

---

## 🚀 Principais Funcionalidades (Features)

* **Hero Section de Produto:** Apresentação inicial destacando o design e os principais diferenciais do smartwatch.
* **Storytelling Visual do Produto:** Seções dedicadas para apresentar funcionalidades como monitoramento de saúde, modos esportivos e autonomia de bateria.
* **Layout Inspirado em Product Pages de Tech Brands:** Estrutura semelhante às páginas utilizadas por fabricantes de tecnologia.
* **Design Responsivo:** Interface adaptável para **Mobile, Tablet e Desktop**.
* **Seções Visuais de Recursos:** Apresentação clara das funcionalidades e especificações do dispositivo.
* **Performance Front-end:** Estrutura leve e otimizada para carregamento rápido.

---

## 🛠️ Tecnologias Utilizadas

Neste projeto foi adotada uma abordagem **clean e performática**, priorizando controle da interface e carregamento rápido da página.

* **HTML5:** Estrutura semântica e organização do conteúdo.
* **CSS3:** Flexbox, CSS Grid, responsividade, animações e variáveis CSS.
* **JavaScript (Vanilla):** Manipulação de DOM e interações da interface.

---

## 🎨 Abordagem de Design (UI/UX)

Como profissional que une **Design e Desenvolvimento Front-end**, o foco desta landing page foi criar uma experiência visual que valorize o produto e facilite a navegação do usuário.

Principais princípios aplicados:

1. **Hierarquia Visual:** Destaque progressivo das funcionalidades do smartwatch.
2. **Design Orientado à Escaneabilidade:** Conteúdo estruturado para leitura rápida.
3. **Experiência Mobile First:** Interface pensada inicialmente para dispositivos móveis.
4. **Estética Tecnológica:** Visual alinhado com padrões de marcas globais de tecnologia.

---

## 📈 O Impacto (Business Value)

Esta landing page demonstra como **design e front-end podem aumentar a percepção de valor de produtos tecnológicos em páginas de apresentação e e-commerce**.

Principais benefícios desta abordagem:

1. **Valorização do Produto:** Layout moderno que reforça o posicionamento do smartwatch.
2. **Melhoria da Experiência do Usuário:** Navegação clara e intuitiva.
3. **Engajamento Visual:** Seções visuais que incentivam a exploração do produto.
4. **Apresentação Clara de Recursos:** Destaque organizado das funcionalidades do dispositivo.
